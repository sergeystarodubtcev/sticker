    Фон наклейки

    Сейчас: —

    Общая база лотов лежит на GitHub (data/lots.json). Сайт пишет в неё через сервер синхронизации: добавлять и править лоты может любой, а удалять только с паролем. Токен и пароль хранятся на сервере, на сайте их не видно.

    Обычно уже прописан в сайте. Поле нужно, только чтобы попробовать другой сервер на этом устройстве.
    Режим владельца: личный токен GitHub (без сервера, пароль не спрашивается)
    1. github.com → Fine-grained token, Only select repositories → свой репозиторий.
    2. Permissions → Repository → Contents: Read and write. Токен хранится только в этом браузере.

    Приложение на телефон

    Android (Chrome): меню ⋮ → «Установить приложение» или кнопка ниже.
    iPhone (Safari): «Поделиться» → «На экран Домой».
    Приложение работает и без интернета; база подтянется, когда сеть появится.

    Типы наклеек, раскладка и лист хранятся в этом браузере. База лотов — общая, на GitHub.
