# ☕ Кофейные наклейки

База кофейных лотов и конструктор наклеек для печати на А4. Работает в браузере и ставится на телефон как приложение (PWA).

**Сайт:** https://sergeystarodubtcev.github.io/sticker/

## Что умеет
- **База лотов.** Группировка по обжарщикам, месяцу обжарки или странам. Сортировка по дате добавления, дате обжарки и упаковки, названию, Q-баллу. Поиск, фильтр-чипсы по обжарщикам, «свежесть» обжарки в днях.
- **Конструктор.** Форма с автоподсказками и живым превью наклейки. Типы наклеек со своей раскладкой, фоном и листом. Свои поля.
- **Шаблоны наклеек.** «Основная» (твоя) + 6 готовых: Минимал, Крафт, Эспрессо (тёмная), Круглая Ø50 мм, Бирка 90×45 мм, Поп. Переключаются полосой в конструкторе или выбором «Шаблон» на странице лотов. У каждого свой лист, раскладку можно двигать в Настройках.
- **Лист А4.** Печать, PDF, PNG, CSV.
- **Синхронизация.** База лежит в `data/lots.json` в этом репозитории. Без токена сайт её только читает. С токеном (Настройки → Синхронизация) новые лоты с телефона и с компа сохраняются в репозиторий и видны везде.
- **Приложение на телефон.** Android/Chrome: «Установить приложение». iPhone/Safari: «Поделиться → На экран Домой». Работает офлайн.

## Токен для записи в базу
Fine-grained token: https://github.com/settings/personal-access-tokens/new
→ Only select repositories → `sticker` → Permissions → Contents: **Read and write**.

## Деплой
Сайт раздаётся из ветки `gh-pages`. `.github/workflows/pages.yml` при каждом пуше кода копирует сайт в `gh-pages`,
не трогая базу `data/lots.json` (её пишет само приложение прямо в `gh-pages`).

## Как перерисовать шаблоны
Подложки и раскладка полей описаны в `tools/templates.py` (HTML/CSS → PNG):

```bash
python3 tools/templates.py && node tools/render-templates.js
```
